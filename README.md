# Генератор паролей (JavaScript)

[![hexlet-check](https://github.com/EvelinLin/js-basics-free-project-392/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/EvelinLin/js-basics-free-project-392/actions)

Соберите небольшое, но настоящее приложение — генератор паролей с проверкой надёжности. Оно придумывает пароли из выбранных наборов символов и оценивает, насколько надёжен любой пароль. Проект закрепляет основы программирования (строки, числа, условия, циклы, функции с параметрами) и собирается по шагам. Никаких библиотек и настройки окружения — писать и запускать код можно прямо в браузере.

Учебный проект Хекслета: https://ru.hexlet.io/programs/js-basics-free


## Стек

- Node.js

## Использование

Запустите приложение командой:

node main.js

Программа выведет примеры сгенерированных паролей и результаты проверки их надёжности.
