# Генератор паролей (JavaScript)

[![hexlet-check](https://github.com/EvelinLin/js-basics-free-project-392/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/EvelinLin/js-basics-free-project-392/actions)

Генератор паролей с проверкой надёжности. Он придумывает пароли из выбранных наборов символов и оценивает, насколько надёжен любой пароль.


## Стек

Node.js

## Демонстрация работы

```text
== Генерация паролей ==
буквы и цифры:    5vjehYzZEzZ0
со спецсимволами: X@qzNBCMdbAejoX8

== Проверка надёжности ==
abc        -> Слабый пароль (оценка 1 из 5)
abcdef1234 -> Средний пароль (оценка 3 из 5)
Abcdef123! -> Очень надёжный пароль (оценка 5 из 5)
```
